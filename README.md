# LAST PIXEL — เอาชีวิตรอดบนหมู่เกาะ

เกมเอาชีวิตรอดแบบเนื้อเรื่อง ภาพ pixel art มุมกล้อง 2.5D เล่นบนเว็บได้ทั้งคอม มือถือ และจอยเกม (Phaser 3.90 + TypeScript บน Next.js 15 · เว็บอยู่บน GitHub Pages · เซิร์ฟเวอร์เป็น Google Sheet + Apps Script) กราฟิกในเกมและเสียงสร้างด้วยโค้ด ส่วนภาพประกอบ (หน้าปก ฉากเปิด ตัวละคร บอส ภัยพิบัติ การ์ดเกาะ สัตว์ในตำนาน คลังข้อมูล รวม 79 ภาพ + ภาพตัวอย่างรายไอเทม/มอน 429 ภาพ) เป็นภาพวาดการ์ตูนพิกเซลใน `public/art/`

> รายละเอียดดีไซน์ ตัวเลขสมดุล และโครงสร้างโค้ดทั้งหมดอยู่ใน **[DESIGN.md](DESIGN.md)**

## ภาพรวม

- **บัญชี:** สมัครหรือเข้าสู่ระบบก่อนเล่น บัญชีใหม่จะเลือกหน้าตาตัวละครและตั้งชื่อ แล้วสุ่มได้เกาะส่วนตัว บัญชีที่มีเกาะแล้วกด "ไปเกาะของฉัน" เพื่อกลับเกาะเดิมได้ทันที
- **แผนที่โลกเดียว:** ตาราง 11×11 ช่อง ทุกคนอยู่แผนที่เดียวกัน (สูงสุด 100 คน) ช่องกลางเป็น **เกาะกลาง** ซึ่งเป็นตลาดและห้ามต่อสู้ ช่องล่างสุดเป็น **เกาะมหาสมบัติ** ที่เปิด 1 ชั่วโมงทุก 4 ชั่วโมง (00/04/08/12/16/20 น. เวลาไทย) ไปเกาะอื่นต้องใช้เรือหรือยานบิน
- **เกาะร้างของคุณ:** ไม่มีหมู่บ้านหรือชาวบ้าน ใต้เกาะมีดันเจี้ยน 3 ระดับ (มืด มีมอน หีบ บอส เกิดใหม่ทุกวัน) ล้มบอสครบทั้ง 3 = พิชิตเกาะ
- **เกาะ 14 แบบ + รูปร่าง 6 แบบ:** ป่าสน หิมะ ทะเลทราย ป่าดิบ ภูเขาไฟ ซากโบราณ + ใหม่ 8 แบบ — **หนองน้ำป่าชายเลน** (โคลนเดินช้า หมอกพิษ) · **เกาะเห็ดยักษ์** (เห็ดเรืองแสง สปอร์ลดสติ) · **เกาะคริสตัล** (แร่คริสตัลเพียบ โกเลมคริสตัล) · **ป่าไผ่ซากุระ** (สงบ ไผ่) · **ทุ่งหญ้าสะวันนา** (ฝูงควายป่า อาคาเซีย) · **ธารน้ำแข็ง** (พื้นลื่นไถล หนาวสุด มังกรน้ำแข็ง) · **เกาะปะการังวงแหวน** (ลากูน ปะการังมีไข่มุก ตกปลาดี) · **เกาะหมอกผี** (หมอกหนา ผีออกทั้งวัน หีบสมบัติ) · เกาะมีรูปร่างก้อนกลม จันทร์เสี้ยว วงแหวน ยาวเรียว เกาะแฝดมีสันทรายเชื่อม และหมู่เกาะเล็ก · ขึ้นเกาะแบบใหม่ครั้งแรกมีการ์ดภาพเต็มจอ
- **ทุกคืนมีภัยพิบัติ 12 แบบ:** มอนสเตอร์บุกเป็นระลอก — ซอมบี้ ปูยักษ์ ค้างคาว ฝนอุกกาบาต โกเลม + ใหม่ **คืนจันทร์เลือด** (ฝูงหมาป่า + จ่าฝูง ฟ้าแดง) · **คืนหมอกผี** · **กองทัพโครงกระดูก** (+ แม่ทัพ) · **ฝูงแมลงยักษ์** (+ ราชินีแมลง) · **ทะเลคลั่ง** (ฉลาม หนวดคราเคน) · **สัตว์ในตำนานบุก** (วันที่ 12+) · ทุก 5 วันเป็นคืนราชาปีศาจ ถ้ารอดจะได้กล่องรางวัล
- **ช่วงตั้งหลัก 2 วันแรก:** ยังไม่มีภัยพิบัติ ฟาร์มและสร้างฐานได้เต็มที่ · เริ่มเกมใหม่เลือก **แปลนฐานที่มั่น 1 + อาวุธ 1** เป็นเป้าหมายแรก
- **ภัยพิบัติมาเรื่อยๆ ทั้งวัน 18 แบบ:** แผ่นดินไหว พายุฟ้าผ่า ฝูงสัตว์คลั่ง คลื่นความร้อน หนาวฉับพลัน ไฟป่า อุกกาบาต คลื่นยักษ์ + ใหม่ พายุทราย พายุหิมะ ภูเขาไฟระเบิด ฝนกรด ฝูงตั๊กแตน น้ำท่วม หมอกพิษ สุริยุปราคา พายุทอร์นาโด วังน้ำวน (กลางทะเล) — **สุ่มตามเกาะที่ยืนอยู่** (ทะเลทรายเจอพายุทรายบ่อย ธารน้ำแข็งเจอพายุหิมะ ฯลฯ) · ยิ่งรอดนานยิ่งถี่และแรงขึ้น · **รอดทุกครั้งได้กล่อง**
- **บ้านปลอดภัย:** บ้าน/เตียง/เต็นท์ของเราบนเกาะบ้านมี **เขตปลอดภัย** รัศมี 3–8 ช่องตามขนาด (+0.3 ช่อง/เลเวลอัพเกรด) — ในวงไม่มีมอนเกิดเอง ฟ้าผ่า/อุกกาบาตไม่ตกใส่ ความร้อน/หนาวจากภัยไม่มีผล พักแล้วฟื้น HP/สติ (ภัยกลางคืนยังบุกมา ต้องมีกำแพง+ป้อม) · บ้านหิน/อิฐทนภัย ×0.6 เหล็ก ×0.4 · ไฟป่าไหม้แค่ของไม้ · แผ่นดินไหวรอบเดียวทำบ้านพังไม่ได้ (ซ่อมได้)
- **สมุดแปลน (B):** บ้าน สิ่งก่อสร้าง อาวุธ และไอเทมทั้งหมดสร้างจากแปลนเท่านั้น — ไม่ต้องประกอบชิ้นส่วนเอง กด "สร้างเลย" ได้ของสำเร็จ · แปลนใช้ **ของดิบ** (ไม้ หิน แร่ ถ่าน …) ถ้ามีชิ้นส่วน (เชือก ไม้กระดาน แท่งเหล็ก …) ในกระเป๋าจะใช้ก่อน · สถานีแค่ต้อง **มีอยู่บนเกาะ** ไม่ต้องยืนใกล้ · ของพื้นฐานรู้แปลนตั้งแต่แรก ของขั้นสูง + **แปลนอัพเกรด 42 ใบ** ต้องสุ่มจาก **กล่องทอง/กล่องเพชร** (กล่องเหล็กมีแปลนระดับดี/หายากเล็กน้อย) — แปลน 204 ใบ · ได้แปลน ≥1 ใบ: กล่องเหล็ก 19% · ทอง 43% · เพชร 66% · แปลนใหม่ออกก่อน 70% · **แปลนหลัก** (ทั่ง ป้อมธนู ประตูหิน บ้านอิฐ หอธนู …) ออกก่อนเมื่อสุ่มได้แปลนระดับ "ดี" · **วัตถุดิบนับรวมของในหีบ/โกดังบนเกาะ** (📦 จากคลัง) · 📌 ปักหมุดแปลนให้ HUD บอกของที่ยังขาด · คราฟต์ของที่ซ้อนกองได้ ×1 / ×5 / ×สูงสุด
- **กล่อง 4 ระดับ:** ไม้ / เหล็ก (แปลนเล็กน้อย) / ทอง / **เพชร** · **เกาะของคุณ (รวมดันเจี้ยน ภัยกลางวัน คืนภัยพิบัติ ตู้จดหมาย) ให้แค่กล่องไม้** — ข้อยกเว้น: บอสดันเจี้ยน/คืนบอสให้กล่องเหล็ก · กล่องทอง-เพชรและแปลนหายากต้องไป **เขตผจญภัย** หรือซื้อด้วยเพชรที่เกาะกลาง (4 / 12 เพชร) · รางวัลภารกิจได้ตามเดิม
- **เขตผจญภัย & PvP:** ทุกเกาะที่ไม่ใช่เกาะเรา/เกาะกลาง (เกาะไบโอม เกาะคนอื่น ซากโบราณ เกาะมหาสมบัติ) — ผู้เล่นอื่นโจมตีได้ · **ตายที่นี่ = ตายถาวร เริ่มใหม่** (ไม่สนเลเวล ไม่มีซื้อชีวิต) · ของดีกว่ามาก (มอนลุ้นกล่อง ≈×2 + 25% ขยับขั้น · ภัยกลางวัน +1 ขั้น · หีบสมบัติทอง/เพชร · สัตว์ในตำนานกล่องเพชร ×2.5) · เกาะละ 2–3 **ผู้รอดชีวิตคู่แข่ง** (ชื่อผู้เล่นในห้อง ถือดาบ/ธนูตามวัน หลบ/ป้องกัน/หนี ล้มแล้วได้ถุงของ + ลุ้นกล่องทอง) · ขึ้นเกาะครั้งแรกมีหน้าต่างยืนยัน "ไปต่อ/ถอยกลับ" · ⚠ คู่แข่งยังเป็นบอท (ออนไลน์จะใช้ชื่อผู้เล่นจริงจากเซิร์ฟเวอร์) — PvP สด ๆ ต้องมีเซิร์ฟเวอร์แบบเรียลไทม์
- **อาวุธ 88 ชิ้น + ของขว้าง 10 แบบ:** 20 ชนิด (มีดสั้น ดาบ ดาบสองมือ ขวานรบ ค้อน หอก เคียว แส้ สนับมือ ธนู หน้าไม้ ปืนพก ลูกซอง ไรเฟิล หนังสติ๊ก บูมเมอแรง ไม้เท้าเวท ไม้กายสิทธิ์ คัมภีร์เวท ลูกแก้วเวท) แต่ละชนิดฟีลต่างกัน (ความเร็ว วงฟัน จำนวนเป้า คอมโบ แรงผลัก) · สถานะผิดปกติ ไฟลุก/พิษ/เลือดออก/เยือกแข็ง/มึนงง (บอสต้านทาน) · **อาวุธเวท 14 ชิ้น** (ไม้เท้าวารี/วายุ/ปฐพี/แสงศักดิ์สิทธิ์/โลหิต คัมภีร์อัคคี/ห้วงทะเลลึก ลูกแก้วมังกรน้ำแข็ง/ธรณี …) ร่ายด้วยสแตมินา · อาวุธเทพ 15 ชิ้นพร้อมพลังพิเศษ (ใหม่: คทาพญานาค คัมภีร์ครุฑ ลูกแก้วหงส์เพลิง ทำจากวัสดุสัตว์ในตำนาน) · ระเบิดเพลิง/น้ำแข็ง/ควัน/แสง/แก๊สพิษ/ลูกปราย มีดบิน ดาวกระจาย หอกซัด
- **สิ่งก่อสร้าง 134 ชิ้น:** บ้าน 14 แบบ (เพิงใบไม้ → คฤหาสน์/ป้อมปราการ) · อาคารผลิตอัตโนมัติ (โรงเลื่อย เตาเผาถ่าน เครื่องหลอม รังผึ้ง เล้าไก่ ไซดักปลา โรงเพาะชำ) · ป้อมทะลุ/พ่นไฟ/เทสลา/ปืนครก + กับดักระเบิด/น้ำแข็ง/หนีบ · ครัวทำอาหารเมนูพิเศษ · วัสดุใหม่ ไม้กระดาน อิฐ กระจก เหล็กกล้า · สูตรคราฟต์ 152 สูตร (ชิ้นส่วนกลางไม่ต้องทำเอง)
- **สัตว์และมอนสเตอร์ 54 ชนิด:** (ใหม่: สไลม์บึง โกเลมคริสตัล วิญญาณหมอก หมาป่าจันทร์เลือด อัศวินโครงกระดูก ด้วงยักษ์ + บอส จ่าฝูงหมาป่าเลือด แม่ทัพโครงกระดูก ราชินีแมลงยักษ์) สัตว์ป่าตามเกาะ (กวาง ควายป่า จิ้งจอก ลิงแสม นกแก้ว งูเห่า แมงป่องยักษ์ เพนกวิน ฝูงหิ่งห้อยยามค่ำ ปูเสฉวน) · **สัตว์ในน้ำ** (ฉลาม แมงกะพรุนไฟ ปลาหมึกยักษ์ เต่าทะเล กระเบนราหู ปิรันย่า ปลาไหลไฟฟ้า — โผล่ตอนล่องเรือหรือในน้ำตื้นริมฝั่ง โจมตีเรือได้ ตกปลาทะเลลึกอาจเกี่ยวตัวใหญ่ขึ้นมา) · บางตัวทำให้ติดพิษ/ตัวแข็ง/ไฟฟ้าช็อต
- **สัตว์ในตำนาน 8 ตัว** (ปรากฏตัวพร้อมการ์ดภาพเต็มจอ): พญานาค พญาครุฑ กิเลน หงส์เพลิง (ฟื้นคืนชีพได้) คราเคน (โผล่กลางทะเลลึก ลากเรือ) คชสีห์ มังกรน้ำแข็ง เต่ายักษ์ศิลา — โผล่ยากตามเกาะ เวลา และทะเลลึก ทีละตัว มีหลอด HP บอส ท่าพิเศษพร้อมวงเตือน ล้มได้วัสดุในตำนาน + กล่องทอง/เพชร → ทำอาวุธเวทขั้นสูง
- **ยานพาหนะ 19 คัน:** ทางน้ำ 10 (แพ → เรือรบ เรือดำน้ำ) · ทางบก 7 (เกวียน จักรยาน ม้า ATV มอเตอร์ไซค์ จี๊ป รถถัง) · ทางอากาศ 2 (เครื่องร่อน บอลลูน) · Shift เร่ง · น้ำมันเติมอัตโนมัติ · ห้องเก็บของ ปืนติดยาน เกราะ · ท่าเรือซ่อมเรือ
- **ไม่มีสายอาชีพ:** ความเก่งมาจาก เลเวล + อุปกรณ์ 12 ช่อง + อัพเกรด 10 ระดับ (ไอเทม สิ่งก่อสร้าง ยาน — สำเร็จ 100% เปลี่ยนโฉมที่ Lv4/7/10) + บัฟจากสิ่งก่อสร้าง + ผลึกพลังจากกล่อง
- **ความตาย:** ตายแล้วเลเวลลด 1 ขั้น ของในกระเป๋าตกเป็นถุง และเสียเหรียญ 10% ถ้าตายตอน Lv.1 ต้องซื้อชีวิตด้วยเหรียญหรือเพชร (ราคาแพงขึ้นทุกครั้ง) ไม่งั้นจะ **ตายถาวร** และต้องเริ่มใหม่ · **ตายในเขตผจญภัย = ตายถาวรทันที**
- **ช่วยเล่น:** มีงานอัตโนมัติ (สั่งได้เฉพาะบนเกาะตัวเอง) การ์ดข้อมูลเมื่อชี้หรือจิ้ม ซ่อมทั้งหมดได้ในปุ่มเดียว ลากวางกำแพงต่อเนื่องได้ และมีหน้าคลังอุปกรณ์ & ร้านค้า · สร้าง/คราฟต์/อัพเกรด/ซ่อม **หยิบของจากหีบ/โกดังบนเกาะเอง** · Z ฝากของที่ซ้ำกับในคลัง · จัดเรียง (รวมกอง) ทั้งกระเป๋าและหีบ · 📌 ติดตามแปลน · ของตกดูดเข้าตัวไกลขึ้น (40 px)

- **ออนไลน์ข้ามเครื่อง:** เมื่อตั้ง URL เซิร์ฟเวอร์ (Google Apps Script) บัญชี เซฟ ข้อมูลถาวร แผนที่โลก แผงตลาด และตารางอันดับจะอยู่บน Google Sheet เข้าระบบจากเครื่องไหนก็เล่นต่อได้ เกาะของผู้เล่นจริงขึ้นชื่อบนแผนที่ ช่องที่ยังว่างเติมด้วยบอท · หน้าแรกมีไฟสถานะ 🟢 ออนไลน์ / ⚪ ออฟไลน์ และปุ่ม 🏆 อันดับ
- **ไม่มีเซิร์ฟเวอร์ก็เล่นได้:** ถ้าไม่ได้ตั้ง URL เกมทำงานแบบเดิมทั้งหมด (บัญชี เซฟ และผู้เล่นคนอื่น = บอท 30 คน อยู่ใน `localStorage` ของเบราว์เซอร์) ดูรายละเอียดที่ DESIGN.md หัวข้อ 10

| `npm run dev` | เปิดเกมโหมดพัฒนา (Next.js) ที่พอร์ต 5173 |
| `npm run build` | ตรวจ type แล้ว export เป็นไฟล์เว็บล้วน (static) ลง `out/` พร้อมขึ้น GitHub Pages |
| `npm run typecheck` | ตรวจ type อย่างเดียว (`tsc --noEmit`) |
| `npm run mock-api` | เปิดเซิร์ฟเวอร์จำลองที่ http://localhost:8787 (รัน `backend/apps-script/Code.gs` ตัวจริงใน Node ข้อมูลอยู่ในหน่วยความจำ) |
| `npm run test:api` | ทดสอบทุกคำสั่งของ API กับเซิร์ฟเวอร์จำลอง |

**ลองโหมดออนไลน์ในเครื่อง** (ไม่ต้องมี Google Sheet)

```bash
npm run mock-api
```

```bash
NEXT_PUBLIC_API_URL=http://localhost:8787 npm run dev
```

หรือคัดลอก `.env.local.example` เป็น `.env.local` แล้วใส่ URL (ของ mock หรือของ Apps Script จริง) ไม่ใส่ URL = เล่นออฟไลน์ บันทึกในเครื่อง · `MOCK_DELAY_MS=800 npm run mock-api` จำลองเซิร์ฟเวอร์ช้า

**ดูผล build แบบ GitHub Pages:** `NEXT_PUBLIC_BASE_PATH=/<ชื่อ repo> npm run build` แล้วเปิดโฟลเดอร์ `out/` ด้วย static server ใดก็ได้ (ไฟล์ต้องอยู่ใต้ path `/<ชื่อ repo>/`)

## การ deploy

- **หน้าเว็บ (GitHub Pages):** push เข้า branch `main` แล้ว `.github/workflows/deploy.yml` จะ `npm ci` → ทดสอบ API → `npm run build` (ตั้ง `NEXT_PUBLIC_BASE_PATH=/<ชื่อ repo>` และ `NEXT_PUBLIC_API_URL` จาก repo variable `API_URL`) → อัปโหลด `out/` ขึ้น Pages ให้เอง
  - ตั้งครั้งแรก: repo → **Settings → Pages → Build and deployment → Source = GitHub Actions**
  - เว็บจะอยู่ที่ `https://<user>.github.io/<ชื่อ repo>/`
- **เซิร์ฟเวอร์ (Google Sheet + Apps Script):** ทำตามขั้นตอนใน **[backend/apps-script/README.md](backend/apps-script/README.md)** (สร้างชีต → วางโค้ด → รัน `setup` → Deploy เป็น Web app → เอา URL ไปใส่ที่ repo **Settings → Secrets and variables → Actions → Variables → `API_URL`**)
- ไม่ตั้ง `API_URL` ก็ deploy ได้ เกมจะเล่นแบบออฟไลน์

พารามิเตอร์ URL สำหรับทดสอบ

| พารามิเตอร์ | ผล |
|---|---|
| `?debug` | แสดง hitbox ของฟิสิกส์ |
| `?unlockall` | ปลดล็อกตัวละครและชุดแฟชั่นทั้งหมด |
| `?specialopen` | บังคับให้เกาะมหาสมบัติเปิด |
| `?rivals` | ผู้รอดชีวิตคู่แข่งเกิดทันทีเมื่อขึ้นเกาะผจญภัย (ข้ามช่วงตั้งหลัก) |
| `?legend=<id>` | ให้สัตว์ในตำนานตัวนั้นโผล่หลังเข้าเกม ~6 วิ (`naga` `garuda` `qilin` `phoenix` `kraken` `kochasi` `frost_dragon` `stone_turtle` — `kraken` ต้องล่องเรือบนทะเลลึก/ใกล้น้ำ) |

| ใช้ / คุย / ซ่อม / ขึ้น-ลงยาน / ตกปลา | E | ปุ่ม "ใช้" | Ⓐ |

## โครงสร้างโค้ดโดยย่อ

```
app/            หน้าเว็บ Next.js (App Router): layout (ฟอนต์ viewport) + GameCanvas (mount เกมฝั่ง client)
next.config.mjs output: 'export' → out/ · basePath จาก NEXT_PUBLIC_BASE_PATH
backend/apps-script/  เซิร์ฟเวอร์ Code.gs + appsscript.json + คู่มือติดตั้ง
src/
  main.ts       startGame(parent): สร้างเกม 960×540 + ลำดับซีน (destroyGame ตอนปิดหน้า)
  config/       balance.ts ตัวเลขสมดุล
  core/         AccountService, RoomService (โลกเดียว), SaveManager (v3), MetaSave, SpecialIsland,
                ControlMode, InputManager, Settings, AudioManager, EventBus, RNG
  core/backend/ Api (เรียกเซิร์ฟเวอร์ timeout/retry), Sync (ซิงก์เซฟ/meta เบื้องหลัง + อันดับ)
  data/         items, weapons, equipment, loot (+เพดานกล่อง capBoxTier), level, buildables, vehicles, blueprints, recipes, mobs, rivals, shelter, upgrade,
                disasters, islands, quests, achievements, characters, encyclopedia, palette, sprites
  world/        WorldGenerator, Interiors (ดันเจี้ยน), ChunkRenderer, ChunkManager, tiles, Showcase
  entities/     Player, Mob, Structure, Boat (class Vehicle), ResourceNode, DroppedItem
  systems/      Auto, Interior, Inspect, Disaster, Hazard, Biome (ลักษณะพิเศษของเกาะ), Shelter (บ้านปลอดภัย), Daily, Spawn, Market, Quest,
                Achievement, DayNight, Lighting, Weather, Ambient, CombatFX, Crafting (+MaterialPool), Build, Upgrade, Rival (คู่แข่ง PvP)
  gfx/          PixelCanvas, TextureFactory, TiltPipeline (2.5D), art/* (รวม weapons, buildings2, vehicles)
  ui/           Window, widgets, fancyButton, BlueprintWindow, art
  scenes/       Boot, Title, CharacterSelect, RoomSelect, Catalog (+catalog/*), Game, UI
public/art/           ภาพประกอบ 79 ภาพ (โหลดผ่าน src/ui/art.ts)
public/art/items/     ภาพตัวอย่างรายไอเทม/มอน/อาคาร 429 ภาพ + thumb/ + index.json (หน้าคลังโหลดเมื่อเลือกดู)
tools/gen-batch.mjs   สร้างภาพประกอบทั้งชุดผ่าน Image API (อ่านคีย์จาก .env) ไม่ใช่ส่วนของเกม
tools/gen-items.mjs   สร้างภาพตัวอย่างรายไอเทม (อาวุธเทพ ยาน อาคาร) ลง public/art/items/
tools/gen-items-all.mjs  ภาพตัวอย่างที่เหลือทั้งหมด (วัตถุดิบ อาหาร มอน แปลน ฯลฯ)
tools/mock-backend.mjs   เซิร์ฟเวอร์จำลอง (รัน Code.gs ใน Node + ชีตในหน่วยความจำ) · tools/test-api.mjs ทดสอบ API
```

ไฟล์ `.env` เก็บ API key ของบริการสร้างภาพ อยู่ใน `.gitignore` และไม่ถูกรวมเข้าไปในโค้ดเกม (Next.js ใส่ลงหน้าเว็บเฉพาะตัวแปรที่ขึ้นต้นด้วย `NEXT_PUBLIC_`) · โฟลเดอร์ `screenshots/` และ `art/generated/` ไม่ถูก commit (ไฟล์ใหญ่/ไฟล์ทดลอง)
